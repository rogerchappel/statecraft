# Contributing

Thanks for helping keep state recipes reviewable.

## Local setup

```sh
npm install
npm test
bash scripts/validate.sh
```

## Pull requests

- Link an issue or task before requesting review.
- Keep rule changes paired with fixture updates.
- Explain score changes in the PR body.
- Do not add code mutation behavior without an explicit design doc and safety review.

## Commit style

Use small, meaningful commits. A good Statecraft commit changes one rule, fixture, doc, or interface at a time.
